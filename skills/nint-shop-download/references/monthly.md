# 月度童装热销榜

确认目标年/月后执行：

```sh
"$NINT_NODE" "$NINT_SKILL/scripts/download-month.mjs" YYYY-MM
```

输出在 `$NINT_OUTPUT/YYYY-MM/童装_婴儿装_亲子装/`：原始下载、前100 XLSX、`店铺下载队列.json`、`source-verified.json`、`核验结果.json`、预览。运行日志重定向到输出目录，发生错误时保留现场；不把只出现下载事件记成成功。

已有原始“店铺详细数据”且用户允许复用时，可在新的输出目录执行：

```sh
"$NINT_NODE" "$NINT_SKILL/scripts/download-month.mjs" YYYY-MM '/absolute/raw.xlsx'
```

脚本本地验收要求：`QBT`、`下载条件`；模块“行业分析-热销店铺-店铺详细数据”；天猫全部；目标月起止；类目“童装/婴儿装/亲子装”、ID `50008165`；整月日期；排名连续、销量降序；前100店铺链接唯一。原始13列逐单元格保留，原始下载不重写。

前100构建使用捆绑 `@oai/artifact-tool`，Python只读工作簿核验。执行导出前依当前表格技能要求记录 authoring 操作；输出后查看 main、metrics、conditions 三份预览，确认未截断、格式正常。队列绑定生成文件的哈希，商品阶段会再次核对来源。

页面结构变化时先用CLI快照确认差异，再修复当前步骤；不要在“母婴”父级直接检索。固定口径是童装天猫月榜，用户改类目或范围时须同时更新导航、条件校验、输出命名，不能只改URL或标签。

阶段一完成不代表100家商品下载完成。只下载月榜的请求到此结束；完整留存请求继续逐店阶段。
