# 情报通每月童装热销店铺TOP100数据留存

完成用户指定范围：只要月榜就执行阶段一；要求完整留存则继续阶段二直到队列完成；续跑先用 `shop-queue.py audit` 核对现有文件和队列。创建或修改此 skill 本身不意味着重新下载业务数据。

## 每次先确认店铺范围

开始新一轮采集前先问：“本次按照默认165家店铺列表抓取，还是需要新增店铺？”用户已经在当前请求明确指定名单或新增店铺时视为已回答；本轮续跑不重复提问。等待范围确定后才开始联网采集。

默认名单为 [references/default-shops.json](references/default-shops.json)，来自用户2026-11-12提供的《热销前100店铺列表.xlsx》，实际165家唯一店铺，按原顺序保存。文件名含“前100”不代表只有100家，不截断名单，也不把它当成每月实时TOP100。用户选新增时先收集名称，与默认名单去重；只在用户明确要求保存时更新默认名单。

默认名单模式跳过阶段一，直接按已选名单执行阶段二；仅当用户要求更新当月榜单时才执行阶段一。补抓先按掌柜名/店铺名核对已有文件并验证哈希；仅下载缺失项，保留旧文件。保存新旧文件各自实际统计期间。

清单队列使用 `sourceKind: shop-list`，绑定本次复制的默认JSON或用户单列无表头XLSX及SHA256；`rank`表示清单序号，`shopName`和`shopUrl`未知时用null，不能猜测。查找时精确匹配掌柜名，唯一命中后记录可见店铺名及sid，文件按sid和可见身份验收。月榜队列继续执行100家榜单校验。

## 固定口径

- 月榜入口：**行业分析 → 母婴 → 童装/婴儿装/亲子装 → 热销店铺**。不能省略童装子类目。
- 默认天猫全部、销量降序、月报起止月份均为目标 `YYYY-MM`。明确年份，不能把示例月份当作本月。童装 `cid=50008165`，母婴父级 `rcid=2011010117`。
- 下载选“店铺详细数据”。平台原始导出可能含300家，保留原件，核验后提取排名1—100；不要只抓屏幕可见行。
- 商品入口：**店铺分析 → 店铺列表搜索掌柜名 → 查看详情 → 宝贝列表 → 下载 → 带图（前3000）**。按店铺ID核对身份。
- **严格串行**：上一家下载事件结束、文件落盘并通过内容核验后，才搜索下一家。随机等待2—5秒，加载状态另行轮询；不并发、不通过取消等待提速。
- 月榜月份与商品表自身统计期间分别记录。未验证商品日期选择时，不把“本月/上月”字段当成所选历史月份。需要指定历史商品月且界面不支持时，报告限制，不改写下载条件。

## 环境与复用

只调用已有情报通 CLI，使用工作台专用 Chrome/profile；不连接日常浏览器，不复制 Cookie，不通过私有接口绕过权限。脚本不包含 CLI、账号或浏览器资料。

读 [references/setup.md](references/setup.md) 设置工作台、独立输出目录及运行依赖。每次新下载用新目录；同一任务续跑复用原队列。避免重写已经完成的成果。

## 阶段一：月榜

读 [references/monthly.md](references/monthly.md)。运行 `scripts/download-month.mjs YYYY-MM`。该脚本负责页面导航、条件读回、原始下载、前100导出、队列和核验；它**不自动启动逐店商品下载**。用户要求完整留存时，阶段一成功后由执行此 skill 的 Agent 继续阶段二，不把脚本返回当作整项完成。

可传入已下载原始文件进行本地重建，仍须验证童装类目ID、整月期间、天猫范围、连续排名、销量降序和100家唯一店铺。榜单文件及原始下载条件保留，队列搜索词使用“掌柜名”。

## 阶段二：逐店下载与续跑

读 [references/shops.md](references/shops.md)。Agent 用 CLI 当前快照执行逐店UI动作；`scripts/shop-queue.py` 负责顺序、验收和断点状态，不替代浏览器操作。

`next → 核对可见店铺ID → begin → 下载 → accept`。只有 `accept` 成功才进入下一次 `next`。脚本检查队列与榜单一致、已完成文件仍在且哈希一致、商品表店铺ID、期间、数据行与嵌入图片。历史日志里的“已完成”不足以替代当前磁盘证据。

卡住时先记录当前阶段、`unmet` 和 `observed`，在同一店铺重读状态。失效快照重取；下载超时先检查文件及浏览器下载状态，不直接重复触发导出。明确失败后最多重试当前阶段一次；仍失败暂停该队列，报告具体店铺和原因，不能静默跳过或误记成功。登录、验证码、权限问题交给用户在专用浏览器处理。

## 交付与速度说明

交付可读取的前100 XLSX、原始榜单、每店商品XLSX及实际完成/失败数量。3000条商品标记“达到带图导出上限”；不要声称全店覆盖。保留商品表自己的期间，核验后做代表性视觉检查。业务文件、截图、队列和日志放独立输出目录，不写入 skill 或提交仓库。用户指定的默认店铺名称清单作为可复用配置保存在 skill 中，不包含商品明细、账号或Cookie。

复用脚本与断点可减少找入口、推理和重复下载的耗时；平台加载、导出和传输时间仍占主要部分。未测量同范围任务前，不承诺固定加速比例。
